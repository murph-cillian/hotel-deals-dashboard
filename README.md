# Hotel Deals Dashboard

A Python + Streamlit dashboard that scrapes hotel offers from Rory's Travel Club and presents them in a searchable interface.

## Features

- Live scraper
- Search hotels
- Filter by county
- Filter by province
- Sort by expiry
- Sort by price

## Tech Stack

- Python
- Streamlit
- BeautifulSoup
- Pandas

## Run

pip install -r requirements.txt

streamlit run app.py
